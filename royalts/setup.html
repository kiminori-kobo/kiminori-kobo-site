1. インストール

Windows（Royal TS）

  1. 公式の Downloads ページで、Royal TS for Windows の Download now を押します。x64 版の MSI がダウンロードされます（現行の 7.4 では royaltsinstaller_7.04.50922.0_x64.msi）。ARM64 版と ZIP 版は、同じ欄の Other Downloads（公式 KB「Royal TS V7 Previous Versions」）にあり、各ファイルの sha256 も載っています。
  2. ダウンロードした .msi ファイルをダブルクリックし、画面の指示に従ってインストールします。
  • （一般的な手順で、公式の手順ではありません）ダウンロードしたファイルの sha256 は、PowerShell の Get-FileHash -Algorithm SHA256 <ファイル名> で表示し、上記 KB の値と比べられます。
  • 複数の PC に画面なしでインストールする場合は、msiexec /i [path-to-RoyalTSInstaller.msi] /qn を使えます（公式 KB）。
  • ZIP 版を使う場合は、展開したファイルのブロックを解除します。公式 KB の例：dir '.\RoyalTS\' -Recurse | Unblock-File（PowerShell）。
  • アンインストールは、Control Panel → Programs and Features → Royal TS → Uninstall（Windows のバージョンにより表記が異なります）。

Mac（Royal TSX）

  1. Downloads ページから Royal TSX の .dmg ファイルをダウンロードし、ダブルクリックします。
  2. 開いた Finder のウインドウで、「Royal TSX」を「Applications」フォルダにドラッグします。

2. ライセンスキーの登録

当方経由でご購入の場合、ライセンス情報（「Licensed To」と「License Key」）の届き先（お客様に直接メールが届くか、当方からお送りするか）は、見積書に記載します（販売約款 第6条1）。お客様に直接届く場合に備え、fastspring.com と royalapps.com からのメールを受信できるようにしておいてください。

  1. リボンの File タブを押し、表示された画面（backstage view）で Options を押します（View タブの Options からも開けます）。
  2. Options の License ページを開きます。
  3. License Information の Licensed to と License Key に、メールの記載をそのまま正確に入力します。
  • ライセンスキーを入力すると、Shareware Mode の制限（接続 10 件・資格情報 10 件・ドキュメント 1 つ）がなくなります。
  • 同じページの Reset License を押すと、ライセンスがリセットされ Shareware Mode に戻ります。

画面の表示が上の手順と違う場合は、Help → About の License ダイアログもお試しください。それでも見つからない場合は、contact@kiminori-kobo.com までお問い合わせください。

出典：Options（Open the Options Dialog、License） ／ Licensing FAQ ／ What is Royal TS（2026-10-22 確認）

3. 表示言語の設定

表示言語は、Options の User Interface ページ → General → Language で選びます（Options の開き方は「2. ライセンスキーの登録」の手順 1）。

英語以外の言語はコミュニティによる翻訳で、不完全または不正確な場合があります。

日本語 UI を選べるかは、お見積時にご案内します。公式の配布 ZIP（7.04.50922 x64）に含まれる翻訳ファイルは da / de / en / es / fr / it / nl / pl / pt / ru / zh-Hans の 11 言語分で、日本語（ja）は含まれていません。日本語が選べない場合は English のままお使いください。本ガイドのメニュー名も英語表記です。

出典：Options（User Interface → General → Language） ／ Royal TS V7 Previous Versions（ZIP の配布元）（2026-10-22 確認）

4. 最初の接続を作る

初めて起動すると、Navigation パネルに Application document が表示されます。接続は Application document に直接は追加できないため、まず接続を保存する自分のドキュメントを作ります。

  1. ドキュメントを作る — Home タブの File グループで New を押し、Display Name にドキュメント名を入れて OK。
  2. ドキュメントを保存する — Home タブの File グループで Save を押し、ファイル名を入れて OK（拡張子 .rtsx のファイルができます）。パスワード付きの資格情報を保存する場合は、ドキュメントの Security 設定でパスワード保護することを公式が強く勧めています。
  3. 接続を作る（例：リモートデスクトップ） — Navigation パネルでドキュメント（またはその中のフォルダ）を選び、Home タブの Edit グループで Add → Remote Desktop。Computer Name に DNS 名または IP アドレス、Display Name に表示名を入れて OK。
  4. 接続する — Navigation パネルで接続を選び、Home タブの Actions グループで Connect。セッションのタブが開きます。切断は Actions タブの Common Actions グループの Disconnect です。
