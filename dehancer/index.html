Dehancer とは

Dehancer は、デジタルの写真や映像にアナログフィルムの見た目を与えるフィルムエミュレーション製品です。実際のフィルムを撮影・現像・プリントして作ったフィルムプロファイル（公式：「60+ Films」）とカメラ Log プロファイル（「130+ Camera Log Profiles」）に加え、グレイン（Film Grain）、ハレーション（Halation）、ブルーム（Bloom）などの効果を、DaVinci Resolve や Photoshop などのホストアプリ上、または単体アプリで使えます。

主な利用者は、カラリスト、映像制作会社、写真家です。

Windows では Nvidia または AMD の GPU が必要です。 DaVinci Resolve・Premiere Pro / After Effects・写真用プラグイン・Desktop の Windows 版は、要件が「PC with Nvidia or AMD GPU」です。Assimilate SCRATCH の Windows 版の要件は「OpenCL compatible GPU」、Vegas Pro は未確認です。Intel の内蔵 GPU について、公式は Premiere Pro / After Effects・写真用プラグイン・Desktop の各 Windows 版で「Intel Iris and Intel HD Graphics GPUs are not officially supported」、Assimilate SCRATCH の Windows 版で「may produce unexpected plugin crashes, visual glitches and artifacts」と記載しています（DaVinci Resolve の Windows 版の欄には Intel GPU への言及はありません）。

当方で扱うのは、年払いのサブスクリプション（Studio / Production）と Lifetime（買い切り）の Studio 版のみです。個人向けの Individual プラン（Photo、Photo & Video）と Mobile は扱いません（Dehancer との取り決めによります）。月払いのサブスクリプションは公式サイトから直接ご購入ください。
