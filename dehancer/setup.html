1. 有効化（引換コード／ライセンスの移転）

サブスクリプションは引換コードで、Lifetime はライセンスの移転（Transfer License）でお渡しします。

サブスクリプション：引換コード

  1. Dehancer アカウントを作る — dehancer.com の「Log In」からアカウントを登録します。アカウントの User Profile には「License Management」欄があり、購入したライセンスはここに表示されます（License Basics）。
  2. 引換コードを入力する — ログインした状態で https://www.dehancer.com/redeem を開き、当方からお送りした引換コードを入力して Validate を押します。
  3. ホストアプリで有効化する（下記の「Login and select License」）。

リセラー経由のサブスクリプションは自動更新されません。期限の1か月前に当方からご案内し、次の期間分の引換コードをお送りします。

Lifetime：ライセンスの移転（Transfer License）

  1. Dehancer アカウントを作り、メールアドレスを当方へお知らせください — ライセンスの移転先になります。
  2. 当方がライセンスを移転する — 当方の Dehancer アカウントに発行されたライセンスを、Transfer License でお客様のアカウントへ移転します。移転後、ライセンスはお客様の User Profile の License Management に表示され、新しいアクティベーションキーがお知らせいただいたメールアドレスに届きます（License Basics）。
  3. ホストアプリで有効化する（下記の「Login and select License」、または届いたキーを「Enter License Key」で入力）。

ホストアプリでの有効化（共通）

  1. Login and select License（サブスクリプション・Lifetime 共通）
    • DaVinci Resolve・Ae / Pr・Final Cut Pro：プラグイン画面の下部にある Options の License info を押す → License ウィジェットで Login and select License → Dehancer アカウントでログイン → 一覧から seat を選び Activate plugin → ウィジェットを閉じて再起動。
    • Photoshop・Lightroom・Capture One・Affinity：プラグインの Settings（歯車アイコン）→ Activate Dehancer → 以降は同じ。
    • Dehancer Desktop：Application Settings（歯車ボタンまたは [S] キー）→ License Activation → Activate Dehancer → アカウントでサインインし seat を選ぶ。
  • 有効化にはインターネット接続が必要です（Production プランのオフラインアクティベーションを除く）。
  • サブスクリプションの有効化にはライセンスキーは不要で、「Login and select License」を使います（公式 FAQ：「You don't need a License key to activate a Subscription.」）。Lifetime は、購入時のメールに記載のアクティベーションキーを「Enter License Key」で入力する方法も使えます。
  • サブスクリプションの有効化には最新版の製品が必要です（公式：「may not work with legacy versions」）。
  • Windows で「Plugin activation has been rejected: client is not registered」などのエラーが出たら、C:\Users\<ユーザー名>\AppData\Local\dehancer の com.dehancer.film_pro.v7 フォルダ内の preferences ファイルを削除して、もう一度有効化します（DaVinci Resolve FAQ）。

2. 各ホストへのインストール

どの製品も、製品ページで OS を選んで Download & Try を押すか、Download Center で Host と Product を選んで Show を押して入手します。以下は Windows の手順です。

DaVinci Resolve（OFX プラグイン）

  1. Products → DaVinci Resolve OFX plugins で製品を選び、Windows を選んで Download & Try。zip を展開します。
  2. DaVinci Resolve を終了した状態で、GPU に合うインストーラを実行します：Nvidia は CUDA、AMD は OpenCL。
  3. DaVinci Resolve を再起動し、DaVinci Preferences → System → Memory and GPU で、Nvidia なら CUDA、AMD なら OpenCL を選びます。
  4. Color ページの Library パネルで、Film Emulation の最下部にある「Dehancer」をクリップにドラッグしてノードを作ります。
  5. Dehancer が Library に出ない・読み込めない場合は、DaVinci Preferences → System → Video Plugins で Dehancer のチェックを入れ直し、再起動します。

出典：Dehancer OFX plugin（2026-10-19 確認）

Premiere Pro / After Effects

  1. Products → Adobe Ae, Pr plugins で製品を選び、Windows を選んで Download & Try。zip を展開します。
  2. GPU に合うインストーラ（CUDA / OpenCL）を選んで実行します。Premiere Pro と After Effects は同じインストールを共有するため、両方使う場合もインストールと有効化は 1 回で済みます。
  3. Premiere Pro では新規プロジェクト作成時に GPU レンダラーを選びます：New Project → General → Video Rendering and Playback → Renderer で、入れたインストーラに合わせて CUDA または OpenCL を選択。公式によると、この設定はプロジェクト作成時にしか変えられず、選ばないとソフトウェアレンダラーになり非常に遅くなります。
  4. Premiere Pro は Effects パネルの Video Effects / Film Emulation、After Effects は Effects & Presets の Film Emulation から Dehancer をクリップ（または調整レイヤー）に適用します。

出典：Adobe Ae/Pr plugin（2026-10-19 確認）

Photoshop / Lightroom

  1. Products → Ps, LrC, C1, APh plugin で Windows を選んで Download & Try。zip を展開します。Photoshop 用と Lightroom 用でインストーラが分かれています（同じアクティベーションキーを共有）。
  2. Photoshop：Photoshop 用インストーラを実行 → Photoshop を起動（または再起動）→ 写真を開き Filter → Dehancer → Dehancer Film。写真は sRGB である必要があります（公式：「your file must be presented in sRGB color space」）。
  3. Lightroom Classic：Lightroom.exe を実行 → Preferences → External Editing → Choose で C:\Program Files\Dehancer Lightroom Plugin\DehancerLightroom.exe を指定 → 写真を右クリックして Dehancer を選びます。
  4. Lightroom（CC）：写真を右クリック → Edit In → Browse… で上と同じ exe を指定します。

出典：Photoshop plugin ／ Lightroom plugin（2026-10-19 確認）

Dehancer Desktop（単体アプリ）

  1. Download Center で Host に Standalone を選ぶか、製品ページの Download & Try から入手してインストールします。
  2. インストール後、スタートメニュー（Mac はアプリケーションフォルダ）から起動します。初回起動時に OS がファイルやフォルダへのアクセス許可を求めた場合は許可します。
  3. 初回起動時にフィルムプロファイルのダウンロードを求められます。

3. 初回のプロファイル取得

Dehancer を使う前に、フィルムプロファイルとカメラプロファイルをダウンロードする必要があります（インターネット接続が必要）。

  • DaVinci Resolve：プラグイン設定の最下部にある Check Profiles を押す → Dehancer Profiles ウィジェットで自動ダウンロード → 完了したら OK で閉じる。
  • Premiere Pro / After Effects：通常はインストールの最後に自動でダウンロードされます。されなかった場合は、Dehancer を適用して Effect Controls → Dehancer の最下部の Check Profiles を押します。
  • Photoshop / Lightroom：初回起動時に開く Settings で Update Film Profiles を押します。
  • Desktop：初回起動時の案内に従うか、Application Settings → Film Profiles の Update Profiles を押します。

画面が真っ黒になる場合はプロファイルが取得できていません。Check Profiles を押して取得し直してください（公式 FAQ）。取得自体が失敗する場合は次の項を参照してください。

4. 日本語 Windows での「Profile Fetcher Error」

Windows でプロファイル取得時に「Profile Fetcher Error」が出た場合、公式 FAQ の対処は次のとおりです。

  1. まず別のネットワーク（スマートフォンのテザリングなど）に接続するか、VPN を使って取得し直します。
  2. それでも直らない場合は、管理者としてサインインし、スタートメニュー → Settings（歯車）→ Time & Language → Language → 右側の Administrative language settings → Administrative タブ → Change system locale を開きます。Windows のバージョンによっては、Settings → Time & Language → Date, time, & regional formatting → Additional date, time, & region settings → Region → Administrative → Change system locale にあります。
  3. BETA: Use Unicode UTF-8 for worldwide language support にチェックを入れ、PC を再起動します。

メニュー名は公式の英語表記です。日本語版 Windows での表記は未確認です。公式はこの不具合と日本語環境との関係を明記していません。この設定は名前のとおりベータ機能で、システム全体に効くため、変更前に他のアプリへの影響をご確認ください。

出典：DaVinci Resolve FAQ（Known Issues and Fixes [Windows]）（2026-10-19 確認）

5. プレビューが半分しか表示されないとき

GPU に合わないインストーラを入れています。Nvidia は CUDA、AMD は OpenCL のインストーラで入れ直してください。インストーラの説明は配布 zip 内の Please_Read_Before_Installing にあります（公式 FAQ）。

GPU 要件は「0. 対応環境」をご覧ください。

出典：DaVinci Resolve FAQ（2026-10-19 確認）

6. Lifetime キーとサブスクリプションの違い

  • Lifetime：製品ごとにライセンスがあり、1 ライセンスに 2 つのアクティベーションキー（2台分）が含まれます。キーは特定のホストアプリ専用で、たとえば DaVinci Resolve 用のキーは Final Cut Pro 用プラグインの有効化には使えません。OS をまたいでの利用は可能です（License Basics）。
  • サブスクリプション：このホスト制限がなく、どのホストの Dehancer プラグインも有効化できます（公式 FAQ：「These restrictions are not present in the Subscription plans」）。Studio は 1台（ワークステーション）につき 1 seat です。
  • 写真用プラグインは Photoshop 用と Lightroom / Capture One 用でインストールが分かれますが、同じアクティベーションキーを共有します。

出典：License Basics（License compatibility、Plans description） ／ DaVinci Resolve FAQ（2026-10-19 確認）

7. 使い終わったら／ライセンスの移転

有効化の解除

  • プラグインを削除する前、OS を再インストールする前、PC を替える前に、有効化したバージョンの Dehancer の画面（License info）から Deactivate します。この方法なら解除の回数に制限はありません。
  • サブスクリプションは、User Profile の Deactivate all seats ボタンで全 seat をまとめて解除できます。
  • Desktop は、Application Settings → License Activation → Manage Your Subscription から解除します。

ライセンスの移転（Transfer License）

  1. dehancer.com にログインし、User Profile の License Management を開きます。
  2. 対象のライセンスで Transfer License を押します。
  3. 移転先アカウントのメールアドレスを入力して Continue → 内容を確認して Transfer。
  4. 元のアカウントのライセンスは無効化・取消され、新しいアクティベーションキーが移転先のメールアドレスに送られます。元のアカウントの seat はすべて解除されます。

利用規約（ToS 4.3）により、組織の外への seat の移転はできません。移転は担当者の交代など、同じ組織内のアカウント間に限ってください。
