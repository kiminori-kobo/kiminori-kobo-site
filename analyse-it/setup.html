0. 対応環境

項目ナレッジベース・最新版 6.24 のリリースページ管理者ガイド（v6.24.0）
ExcelExcel 365、2024、2021、2019、2016 のデスクトップ版（32 ビット・64 ビット）。Excel 2013 も動くが、Microsoft のサポートは終了（ナレッジベースのみの記載）Excel 2013 以降（Microsoft 365 を含む、32 ビット・64 ビットのデスクトップ版）
OSWindows 11、10、Windows Server 2016 以降。Windows 8 も動くが、Microsoft のサポートは終了（ナレッジベースのみの記載）Windows 8、10、11、Windows Server 2016、2019、2022
Mac・ブラウザ版非対応。Windows 版の Excel（デスクトップ版）が必要です
インターネット接続自動での認証、アップデートの確認に使います。ファイアウォールの内側では、license-server.analyse-it.com への TCP 443（HTTPS）を開けます。インターネットに接続できない PC は、別の端末で取得したアクティベーションコードで認証できます
  • Analyse-it は、お使いの Excel と同じビット数（32 ビット／64 ビット）の版を入れる必要があります（管理者ガイド：「Install the version of Analyse-it that matches Microsoft Excel.」）。
  • 公式のページ同士で、対応する Excel と Windows の書き方が少し違います（上の表）。Excel 2013・Windows 8 をお使いの場合は、試用版で動作をご確認ください。

1. 試用版で動作を確かめる

  • Download 15-day trial（英語）— 15 日間の試用版のダウンロード。全エディションの全機能を試せます。試用中は分析結果に透かしが入り、結果とグラフをブックの外にコピーできません（Help articles）。

2. インストール

  • Installation（英語）— インストールの章の入口。
  • Choosing how to install（英語）— インストーラーの種類（EXE と MSI）と、自分だけに入れるか PC の全ユーザーに入れるかの選び方。
  • Installing the software（英語）— 1 台ずつインストールする手順。
  • Deploying the software（英語）・Installer properties（英語）— IT 管理者向けの一括展開。
  • Uninstalling the software（英語）— アンインストール。

購入後の製品版は、Download（英語）のページで製品キーを入れて入手します。当方経由でご購入の場合の製品キーのお渡し方法は、Analyse-it に確認中です。

3. ライセンスの認証

  • Licensing（英語）— 永続・年間、指名ユーザー・フローティングの違い。
  • Activating a license（英語）— 製品キーでの認証。インターネットに接続できない場合の手動の認証もここにあります。
  • Deactivating a license（英語）・Moving a license to another computer（英語）— PC を入れ替えるとき。
  • フローティングライセンス：Acquiring a concurrent license・Releasing a concurrent license・Finding out who is using a concurrent license（いずれも英語）。

4. 使い始める

  • Getting Started（英語）— リボンのタブと作業ウィンドウの構成。
  • Preparing & Arranging Data for Analysis（英語）— 分析用のデータの並べ方。
  • Working with Analyses & Reports（英語）— 分析の作成と再計算。
  • Tutorials（英語）— 統計の例題。
  • Statistical reference guide（英語）— 各分析の解説。

5. アップデートと保守

  • Software Updates & Maintenance Renewal（英語）— アップデートと保守の関係。
  • Updating the software（英語）— アップデートの手順。
  • Checking maintenance expiry and renewing（英語）— 保守の期限の確認と更新。当方経由でご購入の場合は、保守の更新と年間ライセンスの更新も当方からご購入いただけます。

6. うまく動かないとき

  • Troubleshooting（英語）— Excel に Analyse-it のタブが出ないときなどの確認の入口。
  • Checking Microsoft Excel and Analyse-it match（英語）— Excel と Analyse-it のビット数が合っているかの確認。
  • Enabling the add-in（英語）・Repairing the installation（英語）— アドインの有効化と、インストールの修復。
  • Troubleshooting guide（英語）— 公式のトラブルシューター。
