Excel で併行精度・室内再現精度を求める

Analyse-it（Microsoft Excel のアドイン）を使う方法 · 対象の版 Analyse-it 6.24 · 公式ページ確認日 2026-11-18

本ページは Analyse-it 公式の手引き（analyse-it.com の User Guide・Tutorials）を日本語で整理したものです（確認日 2026-11-18、対象の版 Analyse-it 6.24）。各項に公式ページの URL を添えています。メニュー名・ボタン名は公式の英語表記のまま書いています。

何を調べる分析か

同じ試料を繰り返し測ったときに、値がどれだけそろうか（精度）を、標準偏差（SD）や変動係数（CV）で表す分析です。臨床検査では CLSI EP05（精度の確立）と EP15（メーカーの公称値の検証）で使われます。

  • 併行精度（repeatability） — 同じ手順・操作者・装置・場所で、短い時間に測ったときのばらつき。
  • 室内再現精度（within-laboratory precision） — 同じ施設・装置で、長い期間にわたって測ったときのばらつき。校正、操作者、試薬ロットの変化を含みます。日常の検査結果について示すべきなのはこちらです。
  • 大きさは、併行精度 ≤ 室内再現精度 ≤ 施設間の再現精度の順になります。
  • 精度は、日・ランなどの要因ごとの分散（分散成分）を足し合わせて求めます。足すのは SD ではなく分散です（SD 3 と 4 を合わせると 5 で、7 ではありません）。

出典：Precision ／ Measurement conditions ／ Precision components explained（2026-11-18 確認）

Excel の標準機能ではできない点

Excel の分析ツール（Analysis ToolPak）の分散分析は、一元配置と二元配置（繰り返しあり・なし）だけで、日の中にランが入るようなネストした要因の分散成分は出ません。分散成分の信頼区間（Satterthwaite の方法など）や、メーカーの公称値との比較も、自分で数式を組むことになります。

出典：Use the Analysis ToolPak（Microsoft）（2026-11-18 確認）

Analyse-it での手順

データの並べ方

  • 1 行に 1 回の測定を置きます。列は、測定値と、要因（日・ランなど）、必要なら試料の水準（濃度）です。
  • 各水準で、重複測定が 2 つ以上必要です。重複を 1 行に横に並べても構いません。

出典：Study design（2026-11-18 確認）

精度を求める

  1. リボンの Statistical Analyses から Precision を選び、計画に合う型を選びます。単一施設でランを要因にするなら 1 Factor、日の中にランが入る EP05 の計画なら 2 Factor Nested、複数施設なら 3 Factor Nested です。
  2. Y に測定値、各 Factor に日・ランなどの列を指定します。水準ごとに分けるときは By に水準の列を指定します。
  3. 必要なら、許容できる不精密さ（SD か CV%）を入れます。
  4. Calculate を押します。信頼区間の方法として、公式は Exact／MLS を勧めています。

出典：Estimating precision ／ Tutorial: EP05-A3（2026-11-18 確認）

メーカーの公称値と比べる（EP15）

  1. Test（チュートリアルでは Test Claim）を加え、併行精度と室内再現精度の公称値（SD か CV）を入れます。
  2. 有意水準 5% で、複数の水準をまとめて検定するときは Familywise error rate に印を付けます（5% を水準の数で割った値が、各水準の有意水準になります）。

出典：Testing a precision claim ／ Tutorial: EP15-A3（2026-11-18 確認）

結果の見方

  • ばらつきのプロット — ランの平均・日の平均・全体の平均が線で示されます。外れた点や、日を追ったずれ（ドリフト）がないかを目で確かめます。
  • 分散成分の表 — 併行精度と室内再現精度の SD・CV が出ます。詳しい表には、成分ごとの信頼区間が出ます。
  • 精度プロファイル — Profile を加えると、濃度と不精密さ（CV% など）の関係を曲線で表せます。
  • 公称値の検定 — 有意でなければ緑、有意なら赤で示されます。赤ならメーカーに相談します。有意でなくても推定値が公称値よりかなり大きいときは、データを増やして確かめ直すことを考えます。
  • 外れ値 — 結果を Clone で複製し、外れ値を除いた結果と並べて比べられます。

出典：Tutorial: EP05-A3 ／ Tutorial: EP15-A3（2026-11-18 確認）
