BackupChain とは

Windows Server・Hyper-V・VMware 向けのバックアップソフトで、ファイル・データベース・仮想マシンを、ネットワーク上のサーバー・USB・FTP などへバックアップできます。

ライセンスの種類

買い切り（永続）で、サーバー（ホスト）1 台ごとのライセンスです（仮想マシンの数は数えません）。サポート（英語）とアップデートは 2 年込みで、期限後もそのまま使えます。更新は期限から 3 か月以内なら定価の 25%、それ以降のアップグレードは定価の 50% です。Server Edition はバックアップに使う CPU が 2 コアまでで、ディスクイメージと仮想マシン内のファイル単位のバックアップ・復元は Server Enterprise と Platinum の機能です。Server と Server Enterprise のサポートは米国東部時間の平日 9〜17 時、Platinum は 24 時間で、Platinum には開発元によるバックアップの保守・監視が付きます。ライセンスは、アンインストールして無効化すれば、別のサーバーへ移せます。
