0. 対応環境

PC（Rhino）

  • Rhino 7 以降、Windows / Mac。 公式ダウンロードページ：「Free to download and install with the Rhino Package Manager for Rhino 7 or above.」「Fologram for Rhino (Win and Mac)」。プラグインは無料で、Grasshopper 用のコンポーネントも一緒に入ります。

  • 2024.X で、接続に必要だったローカルネットワークとファイアウォールの許可が不要になりました。

1. アカウント作成とライセンスの確認

アカウントの作成

https://app.fologram.com/ を開き、サインイン方法を選んで登録します。画面の選択肢は Sign in with Google / Sign in with Apple / Sign in with Microsoft / Sign in with email です。アカウントは無料です。公式は、Fologram を実際に使う人が日常的に使うメールアドレスでの登録を勧めています（更新・サブスクリプション・請求書の連絡が届くように）。

（当方経由でご購入の場合）登録したメールアドレスを当方にお知らせください。当方から Fologram に発注し、Fologram がこのアカウントにライセンスを付与します。

ライセンスの確認

  • app.fologram.com/account のダッシュボードで、サブスクリプションの確認と変更ができます。
  • 当方経由でご購入いただいたライセンスが、ダッシュボードでどう表示されるかは未確認です。付与のご連絡後に表示が見当たらない場合は、当方までご連絡ください。
  • ライセンスはフローティング方式で、アカウントに紐付けたどのデバイスでも使えます。同時に使うヘッドセット1台につき1シートが必要です。

デバイスをアカウントに紐付ける（Attach Device）

  1. app.fologram.com/account にサインインし、Attach Device を押します。アカウント固有の API キーを含む QR コードが表示されます。
  2. HoloLens 2 またはモバイル端末の電源を入れ、インターネットにつながっていることを確かめます。
  3. デバイスでその QR コードを読み取り（HoloLens では表示される再生ボタンを押す）、案内に従って紐付けます。
  4. 次にモデルをダウンロードするか、セッションに接続したときに、デバイスがアカウントとペアになり、ダッシュボードの紐付け済みデバイスの一覧に表示されます。
  • デバイスをアカウントから外すには、support@fologram.com に連絡します（公式）。
  • Quest をアカウントに紐付ける手順は Docs に記載がなく、未確認です（Release Notes に「account attachment via OTP」への対応とあるのみ）。

2. Rhino プラグインのインストール（Package Manager）

Fologram for Rhino は無料で、Rhino の Package Manager から入れます。Grasshopper 用のコンポーネントも一緒に入ります。Package Manager の利用にはインターネット接続が必要です。

  1. Rhino で PackageManager コマンドを実行するか、Tools > Package Manager を開きます。公式ダウンロードページの LAUNCH RHINO PACKAGE MANAGER ボタン（リンク先 rhino://package/search?name=Fologram）からも開けます。
  2. Online タブの検索ボックスに Fologram と入力し、一覧から Fologram を選びます。
  3. バージョンを選んで Install を押します。
  4. Rhino を再起動してプラグインを読み込みます。
  5. Fologram プラグインが読み込まれたことを確かめ、Fologram コマンドでプラグインのウィンドウを開きます。公式は、このウィンドウを Layers パネルにドッキングしておくことを勧めています。
  • 以前のバージョンが入っている場合 — Release Notes（2024年2月5日）：「Note that due to a Rhino bug old installs should be removed before installing updates.」（Rhino の不具合のため、更新の前に古いインストールを削除してください。）削除は Package Manager の Installed タブで Fologram を選び Uninstall を押します。
  • Rhino 8 では、Package Manager で入れたプラグインは新しいバージョンが出ると自動で更新されます（Rhino 8 ヘルプ）。Rhino 7 では Installed タブで Fologram を選び Update を押して更新します（Rhino 7 ヘルプ）。Quest で使うには最新の Fologram for Rhino が必要で、公式は XRUpdate コマンドでの更新を案内しています。
  • Docs の「Fologram for Rhino」ページにはインストーラーを使う手順（「Just for Me」を選ぶ）が残っていますが、2026-10-22 時点のダウンロードページにインストーラーのリンクはなく、Package Manager へのリンクだけです。

3. デバイスとの接続（QR コード）

デバイスに Fologram のアプリを入れておきます（入手先は「0. 対応環境」の表）。デバイスはインターネットにつながっている必要があります。

HoloLens 2・iPhone / iPad・Android

  1. Rhino で Fologram コマンドを実行してプラグインのウィンドウを開き、Connect を押します（または XRStart コマンド）。
  2. セッションが始まると、接続用の QR コード（アプリへのリンク）がポップアップで表示されます。
  3. デバイスで QR コードを読み取り、コードの上に表示される再生ボタンをタップすると、Fologram が起動してセッションに接続します。先にアプリを起動しておく必要はありません。アプリの起動中に読み取った場合は、再生ボタンの代わりに Connect ボタンが表示されるので、それを押します。
  4. モデルは目の前に実寸（1:1）で表示されます。面をタップしてからデバイスを向けてモデルの軸を合わせると、おおよその位置と向きに置けます。置き直すには、Fologram のメニューのリセットアイコンをタップします。
  5. 2台目のデバイスをつなぐには、もう一度 Connect を押して QR コードを読み取ります。
  6. セッションを終えるには、Rhino で XRStop コマンドを実行します。

アプリを最小化しても、前のセッションに自動で再接続します。QR コードを読み取り直して再参加することもできます。

Meta Quest（PIN コード）

  1. Rhino で Fologram コマンドを実行し、Connect を押します。QR コードの横に PIN コードが表示されます。
  2. Quest で Fologram を起動し、4 桁の接続コードを入力して connect を押します。
  3. セッションが自動で見つかった場合は、数字キーの代わりにそのセッションのボタンが表示されるので、それをタップします。
  4. モデルを置くには、Rhino の原点を置きたい面をコントローラーで指し、トリガーを押したまま x 軸を向けたい方向に向けて、トリガーを離します。

Quest での QR コードの対応は未確認です。Feature Comparison は「QR codes are not currently supported in Fologram for Quest」（Quest では現在 QR コードに非対応）と書いていますが、Release Notes（2026年1月20日、Quest 2024.4.8）には「Added support for using QR codes for Rhino connections, cloud models and markers.」とあります。

4. うまく接続できないときの公式の確認点

QR コードが読み取れない

公式の HoloLens 2 向けの確認点です。HoloLens 2 は QR コードを認識すると緑の枠と再生ボタンを表示します。

  • コードが小さい — ヘッドセットをゆっくりコードに近づけます。画面を拡大するか、大きな紙に印刷してコードを大きくします。
  • 光っている — ノート PC の画面に表示している場合は、画面を傾けて映り込みを減らします。モニターの場合は、画面に映り込む外の光を遮ります。
  • 暗い — 照明をつけるか、画面の明るさを上げます。
  • カメラが使用中 — HoloLens のアプリをすべて終了し、デバイスを再起動します。
  • 余白がない — コードの周りに、できるだけ広い白い余白をとります。

接続できてもモデルが見えない

  • 接続済みデバイスの一覧で「New」のまま — XRStop で実行中のセッションを止めてから、接続し直します。
  • 「Connected」なのに見えない — Rhino の原点に 50 × 50 × 50 cm の立方体を作り、表示されるか確かめます。表示されれば、モデルの縮尺と、モデルが原点にあるかを確認します。表示されなければネットワークの問題の可能性があります。PC とデバイスをスマートフォンのホットスポット（テザリング）につなぎ、Rhino を再起動して試します。

バージョンとネットワーク

  • バージョンをそろえる — 2024.X より前のデバイス用アプリは、2024.X の Fologram for Rhino に接続できません（逆も同様）。Rhino 側とデバイス側を両方 2024.X 以降にします。
  • HoloLens と社内ネットワーク — 公式：「The HoloLens has known issues verifying security certificates with some enterprise networks.」（HoloLens は一部の企業ネットワークで、セキュリティ証明書の検証に問題があることが知られています。）大きなモデルのストリーミングや多数のデバイスでの共有は帯域を使うため、スマートフォンのホットスポット経由では注意が必要です。

プラグインが読み込まれない・不具合を報告する

  • Error: Plugin ID Already In Use — 以前のインストールとの競合で起こることがあります。対処手順は公式の Fologram for Rhino（Troubleshooting common installation issues）にあります。
  • Unable to load plugin: Initialization Failed — 公式は同じページで3つの対処方法を挙げています。
  • 不具合の報告 — support@fologram.com に連絡します。サポートからログを求められた場合は、公式の Reporting Issues の手順でデバイスと Rhino（XRLogs コマンド）のログを送り、それぞれの Reference ID を添えて連絡します。

当方にご相談の際は Reference ID をお知らせください。
