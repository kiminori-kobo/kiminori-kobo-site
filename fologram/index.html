Fologram とは

Fologram は、Rhino / Grasshopper のモデルを HoloLens 2、Meta Quest、iOS / Android の端末に実寸（1:1）で表示し、MR（複合現実）の中で操作できるツールです。Rhino・Grasshopper とデバイスをリアルタイムにつなぎ、設計モデルを変えると MR の表示も変わり、MR 側での変更も Rhino 側に反映されます。QR コードでモデルを実空間に正確に配置したり、Grasshopper のスライダーやボタンを MR の中から操作したりできます。

主なご利用先として、建築設計事務所、施工会社、大学の建築・デザイン系研究室を想定しています。

出典：fologram.com ／ docs.fologram.com ／ Locating models ／ Fologram for Grasshopper（2026-10-22 確認）

対応環境

Rhino 7 以降（Windows / Mac）に、無料の Fologram for Rhino プラグイン（Grasshopper 用を含む）を Rhino の Package Manager で入れて使います。

デバイスは HoloLens 2、Meta Quest（公式サイトの表記は Quest 3 & Pro）、iOS / Android 端末です。接続の開始にはインターネット接続が必要です。

対応バージョン・デバイスごとの違い・ネットワークの詳細は導入ガイドの「対応環境」をご覧ください。

出典：fologram.com/download ／ Connecting and Streaming Models ／ 詳細は導入ガイドの各出典（2026-10-22 確認）

当方で扱うプラン

当方で扱うのは、ヘッドセット（HoloLens 2 / Meta Quest）用ライセンスの年額と 3 年のみです。モバイル版（iOS / Android）は公式サイトから直接ご購入ください。

  • ライセンスはフローティング方式で、アカウントに紐付けたどのデバイスでも使えます。同時に使うヘッドセット1台につき1シートが必要です。
  • HoloLens 2 と Quest は同じヘッドセット用ライセンスで使えます。モバイル用ライセンスはヘッドセットでは使えません（逆も同様）。

購入の流れ

  1. お問い合わせ — プラン（年額 / 3 年）、シート数（同時に使うヘッドセットの台数）、会社名、ご担当者のメールアドレスを contact@kiminori-kobo.com へお送りください。
  2. 見積 — 円建ての見積書をお送りします。有効期限は発行日から 2 週間です。
  3. 前払い（銀行振込） — 見積額を銀行振込でお支払いください。振込手数料はご負担ください。
  4. 領収書 — 入金確認後、領収書を PDF でお送りします。
  5. アカウントの作成 — お客様が https://app.fologram.com/ で Fologram アカウント（無料）を作成し、その登録メールアドレスを当方にお知らせください。手順は導入ガイドをご覧ください。
  6. ライセンスの付与 — 当方から Fologram に発注し、Fologram がお客様のアカウントにライセンスを付与します。
  7. 納品書 — ライセンスの付与後に、納品書を PDF でお送りします。
