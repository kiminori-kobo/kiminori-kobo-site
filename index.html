購入の流れ

  1. お問い合わせ — 製品、プラン、台数（Sublime Text / Sublime Merge は利用者数）、会社名をメールでお知らせください。
  2. 円建て見積 — 見積書をお送りします。有効期限は発行日から 2 週間です。
  3. 前払い（銀行振込） — 見積額を銀行振込でお支払いください。振込手数料はご負担ください。
  4. 領収書 — 入金確認後、領収書を PDF でお送りします。
  5. ライセンス発行 — 入金確認後にライセンスをお渡しします。お渡しの方法は製品ごとに異なり、各製品ページに記載しています（Sublime Text / Sublime Merge はお問い合わせ時にご案内します）。
  6. 納品書 — ライセンス発行後に納品書を PDF でお送りします。
