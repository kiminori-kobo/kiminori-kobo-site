HyperRESEARCH／HyperTRANSCRIBE

質的データ分析と文字起こしのソフト · 開発元 ResearchWare, Inc.

Kiminori Kobo は独立したリセラーで、ResearchWare 社の公式サイトではありません。本ページは Kiminori Kobo（きみのり工房）が運営しています。日本の大学・研究機関・企業向けに、HyperRESEARCH と HyperTRANSCRIBE のライセンスを円建て請求書でご購入いただけます。

見積を依頼する 日本語 導入ガイド

HyperRESEARCH と HyperTRANSCRIBE とは

  • HyperRESEARCH — 質的データの分析を助けるソフトです。音声・動画・画像・文章のデータを扱え、キーワードによるコーディング、マインドマップのツール、理論の構築などの機能があります。Mac と Windows で使えます。
  • HyperTRANSCRIBE — 音声・動画のデータを文字に起こし、テキストファイルにするソフトです。再生をキーボードで操作でき、ファイルを少しずつ再生しながら、1 つのウィンドウで文字を打ち込みます。
  • HyperBUNDLE — HyperRESEARCH と HyperTRANSCRIBE のセットです。両製品のライセンスキーが 1 つずつ付きます。

主なご利用先として、大学・研究機関の質的研究（インタビュー・観察記録などの分析）や、市場調査の部門を想定しています。

まず無料版でお試しください

  • HyperRESEARCH の無料版（Free Limited Edition）は、期限なく使えます。保存や印刷を含めてすべての機能を使えます。ただし、1 つのスタディ（調査のファイル）でコードは 30 まで、ケースは 3 まで、1 ケースのコードの参照は 30 までです。それより大きいスタディも、開いて見ることはできます。
