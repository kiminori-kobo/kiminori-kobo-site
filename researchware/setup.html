1. 無料版で動作を確かめる

無料版（体験版）と製品版は、同じインストーラーです。まず無料版を入れ、買ったあとでライセンスキーを入れると製品版になります。

  • Download HyperRESEARCH（英語）— HyperRESEARCH の無料版（Free Limited Edition）。期限なく使え、保存や印刷を含めてすべての機能を使えます。1 つのスタディでコードは 30 まで、ケースは 3 まで、1 ケースのコードの参照は 30 までです。それより大きいスタディも、開いて見ることはできます。
  • Download HyperTRANSCRIBE（英語）— HyperTRANSCRIBE の体験版。保存・書き出し・コピーなどの一部の命令と、ほかのソフトへのドラッグ＆ドロップが使えないほかは、すべての機能を使えます。

2. インストール

Windows

  1. 上のダウンロードのページから、Windows 用のインストーラー（.exe）をダウンロードして実行します。インストールには管理者の権限が要ります（インストール先の既定は「Program Files x86」フォルダ）。
  2. HyperTRANSCRIBE を使う場合は、無料の LAV Filters を入れます（必須）。HyperRESEARCH で音声・動画を扱う場合も、入れることを強くおすすめします。LAV Filters の説明は、各製品のダウンロードのページと、公式の Media support（英語）のページにあります。

macOS

  1. 上のダウンロードのページから、macOS 用のインストーラー（.dmg）をダウンロードし、インストーラーを実行します。インストールには管理者の権限が要ります（インストール先の既定は「Applications」フォルダ）。
  2. 開くときに警告が出たら、Open を押してインストーラーを実行します。
  3. macOS Catalina 以降では、インストーラーの最後の画面に説明があります。その説明に沿って、HyperRESEARCH（または HyperTRANSCRIBE）に「Full Disk Access」（フルディスクアクセス）を許可します。公式の手順は、Apple メニュー → System Preferences → Security & Privacy → Privacy タブを開き、一覧の Full Disk Access を選び、左下の鍵のアイコンを押してパスワードを入れ、「+」で HyperRESEARCH（または HyperTRANSCRIBE）のアプリを加える、です（macOS のバージョンにより表記が異なります）。
  • インストール後、macOS からアクセスの許可を求められたら、正しく動くように、すべて OK で許可してください。
  • インストール直後は、無料版（体験版）として動きます。
  • USB ドライブにもインストールできます。

3. ライセンスキーを入れる

当方経由でご購入の場合、ライセンスキーは当方からメールでお送りします。

  1. HyperRESEARCH（または HyperTRANSCRIBE）を起動すると、ライセンスキーを入れるか、無料版（体験版）のまま続けるかを聞かれます。
  2. 最初の画面（welcome screen）の License Code の欄に、ライセンスキーを貼り付けます。
  3. キーを入れると制限がなくなり、製品版になります。インストールし直す必要はありません。
  • 現行の HyperRESEARCH 4.x のキーは、「HR」で始まる大文字です（例：HRXX-XXXX-XXXX-XXXX）。4.0 より前のキーは、現行版では使えません。
  • HyperTRANSCRIBE は、2.0.0 より前のキーが現行版では使えません。
  • 入れたキーは、HyperRESEARCH では Help → Show Registration Info、HyperTRANSCRIBE では Help → Registration で確かめられます。
  • キーをなくされた場合は、contact@kiminori-kobo.com へご連絡ください。当方の控えからお送りします。

4. 別のコンピューターに入れる

  • 別のコンピューターにも、無料版（体験版）をインストールし、同じライセンスキーを入れれば使えます。
  • 何台にでもインストールできますが、同時に使えるのは 1 ライセンスにつき 1 台です。同時に使う人の数だけ、ライセンスが要ります。
  • 1 つのキーで、Mac と Windows の両方に使えます。
  • HyperRESEARCH の使用許諾では、購入者が組織の場合、組織の中でキーを割り当て直せます。

5. 使い始める

  • HyperRESEARCH のユーザーガイド、手順を追うチュートリアル、サンプルのスタディは、インストールした HyperRESEARCH のフォルダ（Windows は Programs、Mac は Applications の中）の「Documentation」フォルダに入っています。

6. アップデート

  • 同じメジャー版の中のアップデートは無料です。HyperRESEARCH 4.5.7 は、4.x のキーをお持ちの方への無料のアップデートです。
  • メジャー版が変わるアップグレード（一般に、版番号の最初の数字が変わるもの）は有料で、新しいライセンスキーが要ります。HyperRESEARCH 3.x から 4.x へ、HyperTRANSCRIBE 1.x から 2.x へのアップグレードは、当方からもご購入いただけます（価格は製品ページの「料金」）。
