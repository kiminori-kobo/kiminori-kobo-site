SmartPLS 4 の使い方

導入からブートストラップまで · 対象の版 SmartPLS 4.1.2.1（2026-10-25 公開） · 公式ページ確認日 2026-11-18

本ページは SmartPLS 公式のドキュメント（smartpls.com）を日本語で整理したものです（確認日 2026-11-18、対象の版 SmartPLS 4.1.2.1）。各項に公式ページの URL を添えています。メニュー名・ボタン名は公式の英語表記のまま書いています。画面の細かな流れは、版によって変わることがあります。

1. 導入と認証

ダウンロードと動作環境

  • インストーラは OS ごとに分かれています。Windows は 64 ビット版の .exe、macOS は Apple シリコン用と Intel 用の .dmg、Linux は .sh です。
  • 対応するのは、Windows（Windows 11 を含む 64 ビット版）、macOS Big Sur（11）以降、Linux（動作確認は 64 ビットの Ubuntu 22.04）です。
  • メモリは 2 GB 以上、ディスクの空きは約 200 MB が必要です。
  • SmartPLS 3 とは別の場所に入るので、両方を並べて使えます。SmartPLS 3 のプロジェクトは Files › Import projects from a folder で写しを取り込みます（元のファイルは変わりません）。
  • 新しい版への更新はアプリが自動で行います。うまくいかないときは、インストーラを取り直して上から入れ直します。

出典：Downloads ／ System requirements ／ How to migrate projects

初回の起動

  • 最初に、プロジェクトを保存する Workspace フォルダを選びます。既定では、ユーザーのフォルダの下の smartpls_workspace です。クラウドドライブのフォルダも選べます。
  • あとから場所を変えるときは Files › Choose workspace… を使います。
  • 表示の言語は SmartPLS › Preferences の Language で切り替えます。

出典：First steps ／ Workspace ／ Languages

30 日間の試用を始める

  1. 初回の起動でライセンスの種類を聞かれたら、Free 30-day trial を選びます。
  2. メールアドレスを入れ、届いた確認コードを入力すると試用が始まります。クレジットカードは要りません。
  3. 試用中は Professional のすべての機能が使えます。試用は 1 台のコンピューターにつき 1 回で、別のメールアドレスでもやり直せません。

出典：Free trial ／ Downloads

ライセンスキーを有効にする（ご購入後）

  1. メニューの SmartPLS から Switch License を開きます。
  2. ほかのライセンス（試用や Student など）が有効なら、Deactivate license で外します。
  3. Choose your license type で Professional license を選び、届いたキーを貼り付けて Submit を押します。シートライセンスもフローティングライセンスも、同じ欄に入れます。
  4. 有効期限は、同じ Switch License の画面の Expires で確かめられます。自動では更新されません。

大学などで自前のライセンスサーバーを使う場合は、キーの代わりにサーバーを指定します。管理者向けに、設定ファイル（smartpls.vmoptions）にキーを書いて、画面を出さずに有効にする方法も用意されています。

出典：Activation ／ License days

2. データの読み込み

  • 読み込める形式：CSV、テキスト（タブ区切りも可）、SPSS（.sav）、Excel（.xls／.xlsx）。共分散行列・相関行列も読めます。
  • 生データは、1 行目を指標名にします。
  • 行列のデータには追加の列が要ります。共分散行列は #mean と #cases、相関行列はそれに #stddev を加えます。

手順

  1. プロジェクトを右クリックし、Import Data File でファイルを選んで開きます。
  2. 続く設定の画面で、尺度の種類、最小値・最大値、欠損値を表す値を指定します。この画面はあとから開き直せ、指標の名前の変更や削除もここで行えます。
  3. データファイルが赤く表示されたら、設定が合っていません。ダブルクリックで開き、区切り文字・エスケープ文字・ロケールを確かめます。

欠損値

  • 欠損を表す値（-99 や空のセルなど）は、データファイルの中で 1 つにそろえ、読み込み後の設定でその値を指定します。指定が違うと、欠損が普通の値として計算されてしまいます。
  • 欠損の扱いは、アルゴリズムを実行するときに None・Mean replacement・Casewise deletion・Pairwise deletion から選びます。
  • 公式の目安：欠損がなければ None。指標ごとの欠損が少なく（5% 未満）偶然に生じたものなら Mean replacement。それより多い、または偏りがある場合は、読み込む前に別の方法（多重代入など）を検討します。1 つの指標や回答者で欠損が 15% を超えるときは、外すことを検討します。
  • 4.1.1.5 以降、二値の指標を含むモデルでは Mean replacement は使えません。

出典：Import data files ／ Missing values ／ Different results

3. パスモデルの作成

  1. プロジェクトを作る — Files › New project（ツールバーの New project でも可）で名前を入れて Create。
  2. モデルを作る — プロジェクトを選び、ツールバーの PLS-SEM を押します。モデル名を入れて Save を押すと、モデルの編集画面（Model editor）が開きます。
  3. 構成概念を作り、指標を割り当てる — 左の指標の一覧から指標を選び、右のキャンバスに落とします。構成概念ができるので、名前を付けて ENTER を押します。
  4. パスを描く — ツールバーの Connect を選び、原因側の構成概念から結果側の構成概念へ引くと、矢印（パス）ができます。
  5. 反映型と形成型 — 作った直後はすべて反映型（構成概念から指標へ矢印）です。形成型にするには、構成概念を右クリックして Invert measurement model を選びます。反映型は Mode A、形成型は Mode B の重み付けが既定で、構成概念をダブルクリックすると変更できます。
  6. 配置を整える — ドラッグのほか、右側のツールバーの整列や、右クリックの Align the indicators が使えます。

出典：First project ／ First PLS path model ／ Composite and common factor models

4. PLS-SEM の実行

  1. ツールバーの Calculate から PLS-SEM algorithm を選びます。
  2. ふつうは既定の設定のままで構いません。Open report に印を付けて Start calculation を押すと、結果の画面が開きます。
  3. 結果は保存でき、Excel か HTML に書き出せます。
設定既定メモ
Weighting schemePath weighting scheme公式の推奨。ほかに Factor weighting と PCA
Type of resultsStandardizedほかに Unstandardized と Mean centered
Initial outer weightsすべて +1指標ごとに指定もできる
最大反復回数・停止基準3,000 回・10−7SmartPLS 4 では変更できない
  • 結果では、反復の上限に達したのではなく、収束して止まったことを確かめます。
  • SmartPLS 4 は 0/1 の二値の変数を標準化しません。SmartPLS 3 と同じ結果にしたいときは、データの設定で尺度を Metric にします。

出典：First PLS path model ／ PLS-SEM algorithm ／ Different results

5. 結果の見方

結果の表は、目安を満たす値が緑、注意が要る値が黒、満たさない値が赤で表示されます。色はあくまで目安で、合否の判定ではありません。

主な値の意味

  • パス係数 — 構成概念どうしの関係の強さ。回帰分析の標準化係数（β）に当たります。
  • 外部負荷量（outer loadings） — 指標と構成概念の相関。反映型の測定モデルを評価するときの中心の値です。
  • 外部ウェイト（outer weights） — 形成型で、各指標がどれだけ効いているかを見る値です。
  • R² — 結果側の構成概念のばらつきのうち、モデルで説明できた割合です。

反映型の信頼性と妥当性の目安

値緑になる目安
外部負荷量0.70 以上
クロンバックの α0.70 以上
組成信頼性（rho_a・rho_c）0.70 以上
AVE（収束妥当性）0.50 以上
HTMT（弁別妥当性）0.85 以下（0.90 を超えると赤）
VIF3.00 以下（5.00 を超えると赤）
f²（効果量）0.15 以上（0.02 未満は赤）
  • 負荷量が 0.40〜0.70 の指標は、外すと組成信頼性や AVE が目安を超えるときに限って外す、というのが公式の説明です。探索的な研究では、もう少し低い値が認められることもあります。
  • 信頼性が 0.95 を超えるときは、指標どうしが似すぎている（言い換えの重複）おそれがあります。
  • 弁別妥当性は、結果の Quality Criteria に Fornell-Larcker 基準・交差負荷量・HTMT が出ます。公式は HTMT を勧めていて、0.90 未満なら弁別妥当性があると見ます。
  • 形成型の構成概念には、α・組成信頼性・AVE・HTMT は当てはまりません。VIF と、外部ウェイトの大きさ・有意性などで評価します。

出典：Thresholds ／ Glossary ／ Discriminant validity assessment

6. ブートストラップ

  1. 結果の画面から Edit でモデルの画面に戻ります。
  2. Calculate から Bootstrapping を選び、設定を確かめて Start calculation を押します。
設定既定メモ
Subsamples10,000試しに回すなら 1,000 でも足りるが、最終の結果は 10,000 が推奨
Confidence interval methodPercentile bootstrapほかに Studentized と BCa
Test type—片側か両側かを選ぶ
Random Number Generator—Fixed seed にすると、同じサブサンプル数なら毎回同じ結果になる

結果の見方

  • p 値が 0.05 以下だと緑で表示されます。研究によっては 1% や 10% の水準を使うこともあり、その場合は理由を示します。
  • 信頼区間に 0 が含まれなければ、その係数は有意と見なせます。
  • 両側検定の t 値の目安は、1.65（10%）、1.96（5%）、2.57（1%）です。
  • HTMT を検定するときは、Amount of results を Complete (slower)、検定を片側にして実行し、Quality Criteria の偏り補正済みの信頼区間の上限が 0.90 未満かを見ます。
