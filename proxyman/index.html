Proxyman とは

Proxyman は、PC・スマートフォン・スクリプトが行う HTTP/HTTPS 通信を中間者（MITM）プロキシとして捕捉し、HTTPS を復号して中身を確認し、必要に応じてリクエストやレスポンスを書き換えるためのデバッグツールです。

主な利用者は、モバイルアプリ（iOS / Android）や Web の開発者、API を検証する QA・テストエンジニアです。macOS 版はネイティブアプリ、Windows / Linux 版は Electron ベースです（公式ドキュメントの記載）。

出典：docs.proxyman.com（Overview）（2026-10-19 確認）

公式の日本語版：日本語サイト（proxyman.com/ja） ／ 日本語ドキュメント（proxyman.com/docs/ja）（2026-10-28 確認）

対応 OS

macOS、Windows 10 / 11、Linux（AppImage）。iOS / Android は専用アプリがあり、実機の通信も PC 側で捕捉できます。

対応バージョンの詳細は導入ガイドの「対応 OS」をご覧ください。

主な機能

  • SSL Proxying — 指定したドメインの HTTPS 通信を復号して表示。ワイルドカード（*.example.com）で指定可。公式ドキュメント
  • Breakpoint — リクエスト／レスポンスを途中で止め、ヘッダーやボディを書き換えてから送る。公式ドキュメント
  • Map Local / Map Remote — レスポンスをローカルファイルに差し替える（Map Local）、別の URL に転送する（Map Remote）。Map Local ／ Map Remote
  • Scripting — JavaScript でリクエスト／レスポンスを自動で書き換える。公式ドキュメント
  • iOS / Android 実機 — 実機の Wi-Fi プロキシを PC に向け、証明書を入れて HTTPS を復号。iOS ／ Android
  • そのほか公式ドキュメントに記載のある機能：Compose、Repeat、Diff、Allow List / Block List、External Proxying、No Caching、Protobuf、Network Conditions、Multiple Filters、MCP Support（料金ページの比較表）。

注：macOS 版のアプリは、Proxyman 6.17.0 から日本語の表示に対応しています（Settings → General → App Language で切り替え。公式 Localization（日本語版）、2026-10-28 確認）。Windows / Linux 版と iOS 版で日本語を選べるかは、公式の記載では確認できていません。日本語の導入手順は当方の導入ガイドにもまとめています。
